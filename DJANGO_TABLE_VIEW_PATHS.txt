========================================
C) DJANGO MANAGEMENT COMMAND PATHS (TABLE INSPECTION)
========================================
Run from backend folder:
- backend/manage.py

Useful commands:
1) Show applied migrations (table evolution):
- python manage.py showmigrations

2) Open DB shell (direct SQL table viewing):
- python manage.py dbshell

3) Show SQL for a migration:
- python manage.py sqlmigrate api <migration_number>

4) Reverse-engineer models from current DB tables:
- python manage.py inspectdb

5) Start Django shell for ORM table queries:
- python manage.py shell

Example shell snippet to list tables:
from django.db import connection
print(sorted(connection.introspection.table_names()))
