========================================
E) HOW TO GET JWT TOKEN
========================================

To access protected API endpoints, you need a JWT access token. Here's the process:

1. POST to /auth/login/ with credentials:
   curl -X POST http://localhost:8000/auth/login/ \
     -H "Content-Type: application/json" \
     -d '{"username": "superadmin", "password": "timothy25"}'

2. Response will contain:
   {
     "access": "eyJ0eXAiOiJKV1QiLCJhbGc...",
     "refresh": "eyJ0eXAiOiJKV1QiLCJhbGc..."
   }

3. Use the access token in subsequent API calls:
   curl http://localhost:8000/api/staff/ \
     -H "Authorization: Bearer <access_token>"
